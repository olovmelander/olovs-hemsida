# Upsala authenticated orthophoto review

The live Lantmäteriet STAC search on 2026-09-09 still selects **orto-o2-2025**
as the newest campaign covering Upsala. Authenticated requests returned HTTP
206, exact TIFF signatures and the advertised source byte lengths on both
source tiles. Native RGBI grids were checked against EPSG:3006, 0.16 m pixels,
15,625 × 15,625 dimensions and the catalogued extents before reading pixels.

All 18 Stora and nine Mellan green/bunker review windows are captured on
**2025-06-14**. This date comes from intersecting each window with Lantmäteriet's
published `flygbild` mosaic source polygons, with complete coverage. The much
larger source tiles also contain April or June 15 imagery; their representative
datetimes alone do not identify the pixels used in a particular crop. The
whole-ground overview includes some 2025-04-25 pixels outside the native review
windows. A 2025 photograph cannot verify construction completed in 2026.

## Local files and coordinate mapping

Ignored directory: `upsalabuild/cache/lm-ortho/`.

- `stora-01-surfaces` through `stora-18-surfaces`: 18 native 0.16 m windows.
- `mellan-01-surfaces` through `mellan-09-surfaces`: nine native 0.16 m windows.
- `ground-overview`: 2,811 × 2,811 pixels at 0.8 m, averaged from native data.

Each window has a georeferenced `.tif`, lossless RGB `.png`, pixel-centre `.pgw`,
baseline ring `-overlay.png` and hash/grid `.json` ledger. The overlay uses
green for existing putting surfaces and magenta for existing bunkers; those
outlines are review inputs and do not claim accepted accuracy. TIFF bands are
red, green, blue and near infrared. An explicit dataset validity mask prevents
NIR being interpreted as alpha. All 28 windows have fully valid coverage.

Overview pixel-edge bounds are
`[639019.2, 6635020.8, 641268.0, 6637269.6]` in EPSG:3006.
Its GDAL transform is `[639019.2, 0.8, 0, 6637269.6, 0, -0.8]`.
Every ledger records the corresponding bounds/transform for its own grid:

```text
E = minE + (column + 0.5) * resolution
N = maxN - (row + 0.5) * resolution
```

Plan overlays invert the frozen legacy local frame to WGS84 and use pyproj to
project each vertex to EPSG:3006; they do not apply a visual translation or
rotation. The 0.8 m overview grid divides both 2,500 m source tile widths exactly.
Native windows retain source resolution. Neither grid consistency nor source
ground sample distance measures absolute horizontal accuracy.

## Reproduce on this Windows workspace

The existing ignored `upsalabuild/cache/review-venv` Python environment contains
numpy, Pillow, pyproj, rasterio and shapely. Rasterio 1.4.3 was added to this
environment for source reading; no application dependency was added. The
acquirer reads supported `LANTMATERIET_*` environment variables or the local
ignored `.env`, without writing or logging their values.

```powershell
node upsalabuild/mapping/lm-ortho-discover.mjs
& upsalabuild/cache/review-venv/Scripts/python.exe upsalabuild/mapping/lm-ortho-acquire.py
& upsalabuild/cache/review-venv/Scripts/python.exe upsalabuild/mapping/lm-ortho-capture.py
& upsalabuild/cache/review-venv/Scripts/python.exe upsalabuild/mapping/lm-ortho-verify.py
```

The checked-in plan is pinned to the models before review. Repeated acquisition
uses that plan even if course geometry has subsequently changed. `--replan`
explicitly replaces it with windows derived from the current models.
`--only stora-01-surfaces,mellan-01-surfaces` retries selected windows;
`--probe-only` checks access. Partial selections/probes write their report to
the ignored cache, preserving the complete acquisition ledger. A full failed
run records its failure state and exception type without provider headers.
Verified cached rasters are reused by request and file hashes.

Public evidence in `geo_data/course-v2/upsala/reference/`:

| File | Evidence |
| --- | --- |
| `lm-ortho-catalog-2026-09-09.json` | Live complete-campaign selection and unchanged source URLs/byte lengths |
| `lm-ortho-plan-2026-09-09.json` | Pinned model hashes, native extents, all 28 review windows and baseline overlays |
| `lm-ortho-acquisition-2026-09-09.json` | Actual TIFF-byte access, source-grid checks, window hashes and transforms |
| `lm-ortho-capture-2026-09-09.json` | Per-window source image identities, exact capture times and polygon coverage |
| `lm-ortho-validation-2026-09-09.json` | Offline verification of all 28 windows and 27,255,224 pixels |

Validation checks exact PNG/TIFF RGB equality, source/cache hashes, dimensions,
native extents, EPSG:3006, RGBI band interpretation, independent masks, worldfile
pixel centres and complete capture-date evidence. The inherited bounded-byte
reader tests also pass (three tests). Imagery and credentials remain outside
Git and the runtime course. Acquisition itself does not accept replacement
geometry or establish complete mapping of all course objects.
