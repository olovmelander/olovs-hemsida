Acquisition reuses the pinned baseline plan. `--replan` deliberately replaces the
plan from the current model and must not be used to reproduce existing traces.
`--only angso-01-hole` selects a bounded window, and `--probe-only` checks access.
Credentials are read from existing `LANTMATERIET_*` variables or the ignored `.env`
and are never written to reports.

`boundsEpsg3006` is `[minE,minN,maxE,maxN]` at pixel edges. For a continuous image
point `(x,y)`, use `E=minE+x*resolution`, `N=maxN-y*resolution`. Pixel sample
centres use `(column+0.5,row+0.5)`. Project EPSG:3006 and WGS84 with PROJ, then use
the frozen Ängsö frame: origin `(lon=16.871,lat=59.57390)`, `mPerLat=111320`,
`mPerLon=111320*cos(59.57390°)` (56375.41 after stored-model rounding).

Offline verification passed for 19 windows and 77,348,371 pixels. Checks include
native EPSG:3006 source-grid identity, SHA-256 hashes, exact PNG/GeoTIFF RGB
equality, independent validity masks, worldfiles, complete capture-date footprint
coverage, tile-seam alignment and identical RGBI values in all 32 overlapping
native window pairs. This verifies internal registration; ground sample distance
does not establish absolute surveying accuracy.

The separate tee/water review uses native pixel-edge traces. Reproduce its panels
with `lm-review-front9-tees-water.py` and its JSON with `--write-review`. Physical
tee surfaces do not identify official colour markers. Open-water edges describe
the April capture, and mapped woodland/reeds do not establish visible open water.
Measured water levels are retained separately by the adoption pipeline.
