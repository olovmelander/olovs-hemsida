# Provrunda med kartan

Det här går bara att ta reda på ute på banan. Nio hål räcker. Ladda telefonen först,
och skriv ner batterinivån när du startar om telefonen inte visar den själv.

## Före rundan

- Öppna banan hemma och tryck **Meny → Spara banan**, så fungerar kartan utan täckning.
- Öppna appen från startskärmen om den är installerad där, annars i webbläsaren.

## På banan

Spela som vanligt och lås klubban på varje slag. Lägg inte tid på att vara noggrann,
för det är just vanlig användning som ska mätas.

| Fråga | Vad du tittar efter |
| --- | --- |
| Startkortet | Kom du igång med ett tryck? Var rätt tee vald? |
| Solen | Går siffrorna att läsa utan att skugga skärmen? Prova **Meny → Solläge** i starkt ljus |
| Handskar | Går hjulet att snurra och hålla med handske på? |
| Hållet | Känns 0,9 sekunder rätt? Händer det att du låser av misstag i fickan? |
| Hålbytet | Bytte kartan hål av sig själv på nästa tee? Hände det någon gång fel? |
| Avstånden | Stämmer siffrorna mot banans markeringar och en avståndsmätare? |
| Avslutet | Kom summeringen när sista hålet var ifyllt? Var kortet rätt? |
| Batteriet | Hur många procent gick åt? |

## Efter rundan

Tryck **Meny → Spara provrundans logg** och skicka filen till mig. Skriv gärna två
rader om vad som kändes fel, för loggen kan bara visa vad som hände.

Loggen visar:

- hur bra GPS-positionen var under rundan, en gång i minuten
- varje låsning, och varje håll som släpptes eller gled iväg
- när du fick vänta på GPS:en
- hålbyten, öppnade ark och Ångra
- batterinivån var tionde minut, på telefoner som lämnar ut den
- vilken telefon det är

Den innehåller ingen position, bara hur noggrann positionen var. Loggen stannar på
telefonen tills du själv sparar den, och den håller de senaste 1 500 händelserna.

På iPhone lämnar Safari inte ut batterinivån, så där behöver du läsa av den själv.
